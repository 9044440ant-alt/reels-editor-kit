# Правила монтажа Reels

Документ подставляется в работу при каждом монтаже. Claude составляет `edl.json` строго по нему.
Правка автора = новое правило здесь + кейс в `CASES.md`. Правило без кейса не считается внесённым.
Перед добавлением правила перечитать документ целиком на противоречия.

Это стартовые правила, отточенные на живых роликах. Любое из них автор может поменять под себя.

---

## 1. Начало ролика
1.1. ⛔️ Ролик начинается там же, где начинается исходник. Фразы местами не менять (`hook_move` пустой), если автор не попросил про этот ролик.
1.2. ⛔️ **Плашки-заголовка сверху по умолчанию нет.** Ставить `hook_title` только по прямой просьбе.
1.3. Первые 1,5 с — лицо автора, без вставок: доверие строится на лице.

## 2. Что вырезать — ⛔️ ТОЛЬКО ПАУЗЫ И РАСТЯНУТЫЕ ЗВУКИ (кейс A2)
2.1. Режим по умолчанию — **минимальная обрезка**. Вырезаются ровно две вещи:
   - паузы длиннее 0,3 с (стык остаётся ~0,15 с, речь дышит);
   - растянутые звуки «ааа», «эээ», «ммм», в том числе «голос без слов» (🗣 в расшифровке).
2.2. Всё остальное **остаётся**: вступление, повторы, дубли, «ну», «вот», «короче», «то есть», мета-комментарии.
2.3. Сокращать содержание, переставлять фразы (`hook_move`), убирать хвосты — **только по просьбе автора про этот ролик**.
2.4. Логика аргумента и смысл не трогаются никогда.

## 3. Темп и длина
3.1. Паузы внутри фразы до 0,3 с сохраняются, длиннее — ужимаются до ~0,15 с.
3.2. ⛔️ Длина ролика = длина исходника минус паузы. Содержание ради длины не режется.
3.3. Зум на склейках через раз (100 → 112%), не чаще раза в 1,2 с. Внутри куска медленный наезд 2,5%.

## 3-бис. Звук — ⛔️ НЕ ТРОГАТЬ (кейсы A1, A10)
3-бис.1. В ролик идёт **оригинальная дорожка как есть**. Ни шумодава, ни компрессии, ни эквалайзера, ни нормализации громкости: автоматическая «чистка» испортила звук на первом же живом ролике.
3-бис.2. Разрешено только одно: фейд 12 мс на склейке, иначе слышен щелчок.
3-бис.3. Звуковые эффекты (вжух, щелчок) по умолчанию **выключены** (`"sfx": false`), включать только по просьбе.
3-бис.4. Обработанная копия звука служебная: она нужна распознаванию речи и карте пауз, в видео не попадает.
3-бис.5. Громкость в отчёте QA — справочная цифра. Она должна совпадать с исходником (±0,5 LUFS); больше — значит звук где-то обработали, это ошибка.
3-бис.6. Громкость не поднимать даже чистым усилением. Предлагать, только если автор сам скажет, что тихо.

## 3-тер. Цвет — лёгкий кинематографический грейд (кейс A3)
3-тер.1. На каждый ролик накладывается таблица цветов `assets/luts/look_<пресет>_100.cube` (`reels/grade.py`, создаётся сама при первом рендере).
3-тер.2. Характер: тёплый мягкий свет, янтарные блики, холодно-бирюзовые тени, приподнятый чёрный, аккуратный контраст, приглушённая насыщенность фона.
3-тер.3. ⛔️ **Кожа не желтит.** В грейде оттенки кожи возвращаются к исходному тону. Проверять кадром до/после.
3-тер.4. Пресеты: `soft` (едва заметно), `cine` (по умолчанию), `strong` (заметно), `none` (выключить). Сила `k` 0..1. Выбор — в `config.json → grade`.
3-тер.5. Вставки Higgsfield не грейдятся: они уже в киношной палитре.

## 3-кватер. Субтитры
3-кватер.1. Кегль = базовый размер стиля × `size_k` (по умолчанию 0.9). Размер меняется только этим коэффициентом.
3-кватер.2. Стиль и цвет — из `config.json` (по умолчанию C «заливка», лайм).

## 4. Акценты
4.1. Акцент (цвет) — цифры, деньги, проценты, ключевое слово противопоставления. Не чаще раза в 3-4 с.
4.2. Цифры в субтитрах — цифрами («30%»), не словами. Дроби по-русски: «1,5».

## 5. Вставки
5.0. ⛔️ **Спрашивать автора про вставки на каждом ролике** (кейс A5): предложить конкретные места («на слове X покажу …»), дождаться ответа. Нет ответа — ролик собирается без вставок, платные генерации не запускаются.
5.1. 0-3 вставки на ролик, не чаще одной в 6-10 с. Длительность 1,5-2,5 с.
5.2. `counter` — когда звучит конкретная цифра, которая и есть мысль.
5.3. `card` — один раз на ролик, для главного тезиса; *слово* в звёздочках красится акцентом (одно слово).
5.4. `video` (Higgsfield) — для метафор, мест, предметов, о которых говорится. Вертикаль 9:16, без текста в кадре, без лиц людей. Промпт на английском, кинематографичный свет, тёплая палитра.
5.5. `image` — скриншот новости, поста, таблицы, когда автор на них ссылается.
5.6. Перед генерацией Higgsfield — проверить баланс кредитов. Упала генерация — ставится `card`, ролик не ждёт.

## 6. Текст
6.1. Длинное тире «—» в субтитрах и на обложке заменяется дефисом.
6.2. Ошибки распознавания в субтитрах исправляются полем `fix` в `edl.json`. Спорное место (обе системы распознавания слышат одно, по смыслу другое) — спросить автора, не угадывать.
6.3. Текст поста к ролику — только если автор просит, в его голосе (если у автора есть свой скилл голоса — по нему).
6.4. Шрифт — Unbounded (субтитры и обложка одним шрифтом, кейс A7).

## 7. Перед выдачей
7.1. QA-раскадровка просмотрена глазами: субтитры не на лице, не в зоне кнопок Instagram, вставки к месту.
7.2. `problems` в отчёте рендера пусты или каждая объяснена; `dirty_cuts` пусто.
7.3. Громкость совпадает с исходником (п. 3-бис.5).
