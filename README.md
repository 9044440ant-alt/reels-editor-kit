# reels-editor — личный монтажёр Reels на Claude Code

Сырое вертикальное видео «говорящая голова» → готовый ролик:
- вырезаны паузы и растянутые «ааа/эээ», содержание не тронуто;
- анимированные субтитры (Unbounded, три стиля), ниже лица — положение считается по лицу (Apple Vision);
- лёгкая кинематографическая цветокоррекция без жёлтой кожи;
- лёгкий зум на склейках, по желанию вставки (Higgsfield, карточки, счётчики) и обложка;
- звук оригинальный, без обработки;
- по желанию — приём и выдача через свой Telegram «Избранное».

Монтаж ведёт Claude Code по правилам из `docs/EDIT_RULES.md`: читает расшифровку, составляет план
`edl.json`, рендерит, проверяет раскадровку глазами.

**Установка:** откройте Claude Code и скажите ему:
> Разверни у меня монтажёра по инструкции INSTALL.md из репозитория <ссылка>

Требования: macOS, Homebrew, Python 3.9+, ~3 ГБ под модели распознавания.

```
python3 -m reels doctor
python3 -m reels new <видео> --name 2026-01-01_тема
python3 -m reels render 2026-01-01_тема
python3 -m reels cover 2026-01-01_тема --headline "ЗАГОЛОВОК" --box "ПЛАШКА"
python3 -m reels clean 2026-01-01_тема
```

Шрифты Unbounded, Onest, IBM Plex Mono распространяются по лицензии SIL Open Font License 1.1
(см. `assets/fonts/FONTS.md`).
