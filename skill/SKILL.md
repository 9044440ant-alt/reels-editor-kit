# Монтажёр Reels

Ролик должен выглядеть так, будто его собрал профессионал: ни одной мёртвой паузы, киношная картинка,
субтитры, которые ведут глаз. Речь владельца остаётся его речью: содержание не сокращаю, звук не обрабатываю.

Код: `{{REPO}}`. Настройки: `~/.config/reels-editor/config.json`.

## 0. СНАЧАЛА ПРОЧИТАТЬ, ПОТОМ МОНТИРОВАТЬ
1. `{{REPO}}/docs/EDIT_RULES.md` — правила монтажа целиком.
2. `{{REPO}}/docs/CASES.md` — прошлые ошибки и правки. Ни одну не повторять.
3. `~/.config/reels-editor/config.json` — стиль, цвет, грейд, Telegram.

## 1. ПРИЁМ
- Путь к файлу или свежее видео в `~/Downloads` (AirDrop).
- Если включён Telegram: `cd {{REPO}} && python3 -m reels fetch --list`, затем `--id <id>`. `as_file: false` = видео отправлено со сжатием, посоветовать отправлять файлом.
- На медленной сети большие файлы качаются долго — предупредить владельца.

## 2. ПОДГОТОВКА
```bash
cd {{REPO}} && python3 -m reels new <видео> --name <YYYY-MM-DD_слаг>
```
Печатает текст с индексами слов: `°` паразит, `?` неуверенно, `⏸` пауза, `🗣` голос без слов.
Строка «выравнивание»: если не Vosk — внимательнее к склейкам.
Неуверенные слова (`?`) сверить: спорное место — спросить владельца, не угадывать.

## 3. ПЛАН МОНТАЖА — `edl.json` в папке ролика
⛔️ По умолчанию монтаж минимальный: только паузы и растянутые «ааа/эээ». Черновик `edl.json` уже правильный.
Вырезать содержание или переставлять фразы — только по прямой просьбе на этот ролик.
Поля: `drop` `[[i, j]]`, `hook_move`, `hook_title` (по умолчанию null), `emphasis`, `inserts`, `fix` (`{"индекс": "правильное слово"}`), `tail`, `sfx` (false), `grade`, `style`.
Вставки: `{"word": i, "dur": 2, "kind": "counter", "value": 1.5, "decimals": 1, "suffix": " ЧАСА", "text": "подпись"}`,
`{"word": i, "kind": "card", "text": "*Слово* акцентом"}`, `{"word": i, "kind": "video", "src": "<файл>"}`, `{"word": i, "kind": "image", "src": "<файл>"}`.

## 4. ВСТАВКИ
0. ⛔️ Каждый раз спросить владельца, нужны ли вставки: предложить конкретные места (слово, таймкод, что покажу). Без ответа — без вставок.
1. Видео-вставки генерируются через Higgsfield (если у владельца подключён его MCP): проверить баланс, модель подешевле (`kling3_0_turbo`, 3 с, 720p, 9:16), промпт на английском, `no people, no text`. Результат скачать в `<папка>/inserts/`.
2. Упала генерация — заменить на `card`.

## 5. РЕНДЕР И ПРОВЕРКА
```bash
python3 -m reels render <папка>
```
В отчёте: `problems` и `dirty_cuts` пустые, `lufs` совпадает с исходником (±0,5).
Затем **глазами**: `qa_sheet.jpg` + кадры на вставках (`ffmpeg -ss T -i final.mp4 -frames:v 1 кадр.png`).
Первый ролик без выбранного стиля: `python3 -m reels styles <папка> --sec 8` → показать три варианта.

## 6. ВЫДАЧА
1. Обложка (если нужна): `python3 -m reels cover <папка> --headline "СТРОКА|СТРОКА" --box "ПЛАШКА" --at <секунда с хорошим кадром>` → прозрачный `cover_overlay.png` и готовый `cover_preview.jpg`. Посмотреть глазами. Делать до `clean`.
2. Показать владельцу `final.mp4` и обложку. Если включён Telegram: `python3 -m reels deliver <папка>` (обложки уходят первыми, потом ролик; только в «Избранное» владельца).
3. Записка монтажёра (3-5 строк): что вырезано, итоговая длина, где риск ухода зрителя.
4. ⛔️ Спросить, удалить ли промежуточные файлы (N МБ). Только после «да»: `python3 -m reels clean <папка>`.

## 7. ПРАВКИ
Правка → поправить `edl.json` → `render` заново. Если правка про принцип («всегда крупнее», «не вырезай вдохи»)
→ правило в `EDIT_RULES.md` + кейс в `CASES.md` + коммит. Правило без кейса не внесено.
Смена стиля/цвета/грейда насовсем → `config.json`.

## Грабли (решённые)
- ffmpeg из Homebrew бывает без libass/drawtext: текст рисует Pillow, HDR→SDR через `scale_vt`.
- Whisper выдумывает текст на тишине и ошибается во времени слов — поэтому Vosk + выравнивание по громкости + отсечение выдуманного хвоста.
- `whisper.json` в папке ролика переиспользуется, чтобы индексы слов не ехали; перераспознать = удалить файл.
- У айфона вторая звуковая дорожка пространственная — берётся первая.
- Кадр под обложку — только из `prep.mp4` (команда `cover`), иначе просвечивают субтитры.
